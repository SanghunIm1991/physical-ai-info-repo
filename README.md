# フィジカルAI 最新情報まとめ（日本語）

フィジカルAI（ロボットなど、実世界で身体を持って動く AI。Embodied AI とも呼ばれる）の最新情報を、日本語で整理するリポジトリです。テーマごとに、概要・一次情報へのリンク・ライセンス・確認日・状態をそろえて載せます。初めての人向けに、全体像をつかむための軽い入門書も添えます。

## ご利用の前に

- **この内容は Claude Code（AI）が下書きし、リポジトリの管理者が確認しています。** 新しい内容は、公開した後に確認することがあります。確認の後も、誤りが残っている可能性があります。使う前に、各項目のリンク先の一次情報で確かめてください。
- 載せているのは、各項目の **確認日** の時点の情報です。それ以降に変わっていることがあります。
- 「研究段階」の項目は、開発元が研究・試作向けとしている、論文の実装にとどまる、正式な版が出ていない、などの理由でそう判断したものです（基準は `docs/research_procedure.md`）。「実用」も含め、実際の製品や安全に関わる用途にそのまま使えることを意味しません。
- 論文・ブログ・製品ページの文章や図は転載していません。要約はこのリポジトリが自分の言葉で書いたもので、詳しくはリンク先を読んでください。

## 各項目の読み方

テーマのファイルは、先頭に一覧表があり、その後に種類ごとの見出しで項目が並びます。各項目には次をそろえます。

| 欄 | 意味 |
|---|---|
| 概要 | 何であるかの要約（このリポジトリが書いたもの） |
| 一次情報 | 公式リポジトリ・論文・公式ドキュメント・開発元の発表へのリンク |
| 種類 | OSS／論文／製品／事例（企業の導入の事例）／報告（統計・政府の資料）／解説 |
| ライセンス | OSS・データ等のライセンス（開発元の表記のとおり。該当しない場合は「—」） |
| 状態 | 研究段階／実用（判断の基準は `docs/research_procedure.md`） |
| 確認日 | 一次情報を確かめた日（YYYY-MM-DD） |
| 情報源 | 一次／二次（二次情報は解説記事など。その旨を明記する） |
