# VLM（とVLA）

VLM（Vision-Language Model）は、画像と言語をまとめて扱うモデルです。ロボットでは、カメラの映像から状況を読み取る、言葉の指示を理解する、作業の手順を立てる、といった「考える」部分に使われます。このファイルでは、ロボットの用途の VLM と、VLM を土台にして行動まで出力する VLA（Vision-Language-Action Model）の代表的なものを整理します。汎用の VLM の比較は扱いません。

## VLM と VLA の関係

- **VLM** は、画像と言語を入力に取り、言語（答え・説明・計画）を出力する。ロボットに使うときは、認識や計画を担い、実際の動かし方は別の仕組みに任せる。
- **VLA** は、VLM を土台にして、出力にロボットの動作（関節の目標値など）を加えたもの。Web の画像と文章で学んだ知識を、ロボットの制御に持ち込めることが狙い。RT-2（2023）は、その初期の代表的な例。
- 計画を担う VLM と、動作を担う VLA を組み合わせる構成の例もある。例えば Gemini Robotics では、ER 2（VLM）が計画を立て、VLA を「道具」として呼び出す。Isaac GR00T N1.7 は、VLM（Cosmos-Reason2-2B）を内部の土台として使う VLA である。

## OSS

### Cosmos 3

- **概要**: NVIDIA のフィジカルAI向けの基盤モデル（2026-05 発表）。1つのモデルで、言語・画像・動画・音声・動作の系列を扱う。開発元は、使い方として、(1)複数の種類のデータを理解して推論する VLM、(2)物理的な環境の先の状態を予測する世界モデル、(3)ロボットに作業を学ばせるための土台、の3つを挙げている。大きさの違う Super（64B）・Nano（16B）が 2026-05 に公開され、機器の上で動かす小型の Edge（4B。Jetson でも動かせる）も 2026-07 に公開された（公式リポジトリの表記）。
- **一次情報**: [論文 arXiv:2606.02800](https://arxiv.org/abs/2606.02800)・[開発元の発表](https://nvidianews.nvidia.com/news/nvidia-launches-cosmos-3-the-open-frontier-foundation-model-for-physical-ai)・[公式リポジトリ](https://github.com/NVIDIA/Cosmos)
- **種類**: OSS
- **ライセンス**: OpenMDW-1.1（論文の要旨の記載。コード・モデル・データ・ベンチマーク）
- **状態**: 実用（正式に公開され、開発元はクラウドのサービスとしても提供している）
- **確認日**: 2026-10-18
- **情報源**: 一次

### Isaac GR00T

- **概要**: NVIDIA の、人型ロボットなどに向けた VLA（最初の版 N1 は 2025-03 に論文を公開）。VLM が場面と指示を読み取り、拡散モデルの部分が動作を生成する2段の構成をとる。確認日の時点の最新は N1.7 で、土台の VLM に Cosmos-Reason2-2B を使い、ロボットの動作のデータに加えて人の動画も学習に使っている。独自のロボットに合わせて追加学習する例も用意されている。
- **一次情報**: [公式リポジトリ](https://github.com/NVIDIA/Isaac-GR00T)・[論文 arXiv:2503.14734（N1）](https://arxiv.org/abs/2503.14734)
- **種類**: OSS
- **ライセンス**: コードは Apache-2.0、モデルの重みは NVIDIA Open Model License（README の表記）
- **状態**: 実用（README で N1.7 を一般提供〈General Availability〉の版としている）
- **確認日**: 2026-10-17
- **情報源**: 一次

### openpi

- **概要**: Physical Intelligence による VLA の π0・π0-FAST・π0.5 のコードと、学習済みのモデルを公開したリポジトリ。π0（2024-10 論文）は、学習済みの VLM の上に、動作を滑らかに生成する仕組み（フローマッチング）を載せ、片腕・双腕・移動ロボットなど複数の機体のデータで学習した。π0.5（2025-04 論文）は、Web のデータなども混ぜて学習し、初めて入る家の中で片付けのような長い作業をこなすことを示した。
- **一次情報**: [公式リポジトリ](https://github.com/Physical-Intelligence/openpi)・[論文 arXiv:2410.24164（π0）](https://arxiv.org/abs/2410.24164)・[論文 arXiv:2504.16054（π0.5）](https://arxiv.org/abs/2504.16054)
- **種類**: OSS
- **ライセンス**: Apache-2.0（リポジトリには Gemma の利用条件のファイルも含まれる。その内容は未確認）
- **状態**: 研究段階（README で「実験である」とし、手元のロボットで動くとは限らないと断っている）
- **確認日**: 2026-10-17
- **情報源**: 一次

### OpenVLA

- **概要**: 誰でも使えるように公開された VLA（2024-06 論文）。70億パラメータで、約97万件の実機のロボットの動作の記録で学習した。論文によれば、パラメータ数が約7倍の RT-2-X より作業の成功率が高い。一般向けの GPU でも追加学習できることを示した。
- **一次情報**: [論文 arXiv:2406.09246](https://arxiv.org/abs/2406.09246)・[公式リポジトリ](https://github.com/openvla/openvla)
- **種類**: OSS
- **ライセンス**: MIT（リポジトリの表記）
- **状態**: 研究段階（論文の実装。確認日の時点で、リポジトリの最後の更新は 2025-03）
- **確認日**: 2026-10-17
- **情報源**: 一次

### SmolVLA

- **概要**: 小型の VLA（2025-06 論文）。論文によれば、10倍大きい VLA と同程度の性能で、1枚の GPU で学習でき、一般向けの GPU や CPU でも動かせる。コミュニティが安価なロボットで集めたデータで学習しており、コード・学習済みのモデル・学習データを公開している。ロボット学習のライブラリ LeRobot の一部として提供されている。
- **一次情報**: [論文 arXiv:2506.01844](https://arxiv.org/abs/2506.01844)・[LeRobot の公式リポジトリ](https://github.com/huggingface/lerobot)
- **種類**: OSS
- **ライセンス**: Apache-2.0（LeRobot のリポジトリの表記。モデルの重みのライセンスは未確認）
- **状態**: 研究段階（LeRobot は確認日の時点で 0.6.1 で、1.0 の版が出ていない）
- **確認日**: 2026-10-17
- **情報源**: 一次

## 論文

### PaLM-E

- **概要**: 言語モデルを身体を持つ作業に広げた、初期の VLM の論文（2023-03）。言語モデルに、画像やロボットの状態をそのまま入力として与えて一緒に学習させ、ロボットの作業の計画・画像についての質問への回答・画像の説明を1つのモデルでこなした。論文によれば、Web の多様なデータで学習するほど、ロボットの作業の成績も上がった。
- **一次情報**: [論文 arXiv:2303.03378](https://arxiv.org/abs/2303.03378)
- **種類**: 論文
- **ライセンス**: —（arXiv の標準の配布許諾）
- **状態**: 研究段階（論文）
- **確認日**: 2026-10-17
- **情報源**: 一次

### RT-2

- **概要**: VLM をそのままロボットの制御に使う VLA の、初期の代表的な論文（2023-07）。ロボットの動作を文字列（トークン）として表し、Web の画像と文章のデータと、ロボットの動作のデータで、VLM を一緒に追加学習させた。学習のデータに無い物や指示にも対応できることを示した。
- **一次情報**: [論文 arXiv:2307.15818](https://arxiv.org/abs/2307.15818)
- **種類**: 論文
- **ライセンス**: —（arXiv の標準の配布許諾）
- **状態**: 研究段階（論文）
- **確認日**: 2026-10-17
- **情報源**: 一次

## 製品

### Gemini Robotics ER 2

- **概要**: Google DeepMind の、ロボットの「計画を立てる頭脳」に当たる VLM（2026-07 発表。ER 1.6 の後継）。人との会話、周囲の理解、何段階もの作業の計画、動画からの進み具合の把握、複数のロボットの連携を担う。実際の動作は、開発者が「道具」として登録した VLA などに任せる。
- **一次情報**: [開発元の発表](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/gemini-robotics-er-2/)
- **種類**: 製品
- **ライセンス**: —（API として提供）
- **状態**: 実用（開発元によれば、Gemini API と Google AI Studio で開発者が一般に使える）
- **確認日**: 2026-10-17
- **情報源**: 一次

### Gemini Robotics 2

- **概要**: Google DeepMind の VLA（2026-07 発表）。開発元によれば、人型ロボットの全身や双腕のロボットを動かせ、手の細かな操作も扱う。ロボットの機器の上で動かす軽量版の On-Device 2 も同時に発表された。開発元自身も、多指の手の細かな操作はまだ難しく、作業によって成功率に大きな差があると述べている。
- **一次情報**: [開発元の発表](https://deepmind.google/blog/gemini-robotics-2-brings-whole-body-intelligence-to-robots/)
