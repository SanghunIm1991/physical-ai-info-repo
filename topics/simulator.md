# シミュレータ

シミュレータは、仮想の空間でロボットを動かし、練習や試験をするためのソフトウェアです。実物のロボットでは時間がかかる・壊れる心配がある試行を、計算機の中で大量に、安全に繰り返せます。このファイルでは、ロボットの学習と開発に使われる代表的なシミュレータを、開発元や用途が偏らないように選んで整理します。特定のツールを勧めるものではなく、並びの順は下の分類の順で、優劣を表しません。

- **選び方**: 下の3つの分類のそれぞれから、別の系統のツールを選び、同じ開発元のものは1つの項目にまとめました（MuJoCo Playground は MuJoCo に、Isaac Lab は Isaac Sim に含めています）。ただし Newton は、MuJoCo の開発元（Google DeepMind）と Isaac の開発元（NVIDIA）が Disney Research とともに始めたプロジェクトなので、開発元は一部で重なっています。「開発・試験」の O3DE は、このリポジトリのテーマの [RAI](rai.md) の開発元が、デモと評価に使っていることから選びました。
- **今回は載せていないもの**: CPU だけで動かすことを主にしたシミュレータや、屋内の移動・ナビゲーションの研究向けのシミュレータなどの系統です。次の更新で追加を検討します。そのため今の一覧は、GPU で多数の試行を並列に回す系統の割合が多くなっています。

## シミュレータの分類と選ぶときの観点

ロボットのシミュレータは、大まかに次の3つの層に分けられます。1つのツールが複数の層にまたがることも、別の層のツールを中で使うこともあります。

| 分類 | 何をするか | このファイルの項目 |
|---|---|---|
| 物理エンジン | 物体の動き・接触・関節の力を計算する中核の部分 | MuJoCo、Newton |
| ロボット学習の環境 | 物理エンジンの上に、学習用の課題・ロボットのモデル・センサー・学習の仕組みを載せ、多数の試行を並列に回す | Isaac Sim と Isaac Lab、ManiSkill、Genesis World |
| ロボットのソフトウェアの開発・試験 | ROS 2 などで作ったロボットのソフトウェアを、センサーや環境ごと仮想の空間で動かして確かめる | Gazebo、O3DE（Isaac Sim もこの用途を備える） |

- **層は組み合わせて使われる。** 例えば、Newton は MuJoCo の GPU 版（MuJoCo Warp）を主な計算の部分に使っています。Isaac Lab は、計算の部分として Newton や Isaac Sim などを切り替えて使えます。Gazebo も複数の物理エンジンを使い分けられます。「どれか1つを選ぶ」というより、「どの層に何を使うか」を考えることになります。
- **選ぶときの観点**は、次の3つです。
  - **目的**: 強化学習・模倣学習のために大量の試行を回したいのか、ROS 2 のソフトウェアを試験したいのか。
  - **使える計算機**: このファイルの項目のうち、GPU で並列に回す機能の多くは NVIDIA の GPU を前提にしています。それ以外の GPU に対応するものもあります（各項目の「状態」の注記を参照）。
  - **ライセンス**: 本体のライセンスと、付属のロボットのモデル・3D データ・依存するソフトウェアの利用条件が別になっていることがあります。商用に使う場合は特に確かめてください。

## OSS

### MuJoCo

- **概要**: 関節を持つ物体どうしの動きと接触を、速く正確に計算することを狙った物理エンジン（README が引用を求めている論文は、2012 年の国際会議 IROS のもの）。現在は Google DeepMind が保守している。C 言語の API を中心に、Python から使う仕組みと Unity 向けの部品がある。GPU で動かす版として、JAX で書かれた MJX と、MuJoCo Warp がある。その上に作られた MuJoCo Playground は、歩行・物を扱う作業などの学習用の環境をそろえ、シミュレータで学んだ動きを実機に移す（sim-to-real）までを扱う（開発元の論文によれば、四脚・人型・ロボットハンド・ロボットアームで実機に移した）。
- **一次情報**: [公式リポジトリ](https://github.com/google-deepmind/mujoco)・[MuJoCo Playground の公式リポジトリ](https://github.com/google-deepmind/mujoco_playground)・[MuJoCo Playground の論文 arXiv:2502.08844](https://arxiv.org/abs/2502.08844)
- **種類**: OSS
- **ライセンス**: Apache-2.0（ソースコード。ドキュメントは CC BY 4.0）。MuJoCo Playground も Apache-2.0（地形の画像の一部を除く）
- **状態**: 実用（正式なリリースが続いており〈開発元は毎月の第1週に出すことを目標にしている〉、確認日の時点の最新は 3.16.0〈2026-10-14〉。README に研究用・試験的といった注意書きはない）
- **確認日**: 2026-10-17
- **情報源**: 一次

### Newton

- **概要**: GPU で動く物理エンジンで、ロボットの研究者・開発者を対象にしている。Disney Research・Google DeepMind・NVIDIA が始め、現在は Linux Foundation のプロジェクトとして、コミュニティで開発・保守されている。NVIDIA の Warp（GPU の計算を Python で書く仕組み）の上に作られ、主な計算の部分に MuJoCo Warp を組み込んでいる。3D のシーンの共通の形式である OpenUSD に対応すること、計算の結果を微分できること（学習に使いやすい）、利用者が機能を足せることを特徴に挙げている。Isaac Lab の計算の部分としても使える。
- **一次情報**: [公式リポジトリ](https://github.com/newton-physics/newton)
- **種類**: OSS
- **ライセンス**: Apache-2.0（コード。ドキュメントは CC BY 4.0）
- **状態**: 実用（正式なリリースが続いており、確認日の時点の最新は 1.7.0〈2026-10-14〉。README に研究用・試験的といった注意書きはない）。GPU での計算には NVIDIA の GPU が要る（macOS では CPU だけで動く）
- **確認日**: 2026-10-17
- **情報源**: 一次

### Isaac Sim と Isaac Lab

- **概要**: NVIDIA のシミュレータ。**Isaac Sim** は、NVIDIA の Omniverse の上で動くアプリケーションで、写実的な仮想の環境でロボットを開発・試験・学習させる。URDF・MJCF・CAD などの形式からロボットを読み込め、センサーの模擬、ROS とつなぐ仕組み、学習用のデータを人工的に作る道具を備える。**Isaac Lab** は、強化学習・模倣学習などのロボット学習のための、GPU で並列に回す枠組みで、開発元の論文によれば Isaac Gym の後継にあたる。腕・四脚・人型などのロボットのモデルと、すぐに学習を始められる環境をそろえている。Isaac Lab は計算の部分を切り替えられ（Newton・Isaac Sim など）、すべての使い方で Isaac Sim が要るわけではない。
- **一次情報**: [Isaac Sim の公式リポジトリ](https://github.com/isaac-sim/IsaacSim)・[Isaac Lab の公式リポジトリ](https://github.com/isaac-sim/IsaacLab)・[Isaac Lab の論文 arXiv:2511.04831](https://arxiv.org/abs/2511.04831)
- **種類**: OSS
- **ライセンス**: Isaac Sim のリポジトリのソフトウェアは Apache-2.0。ただし、作る・使うには、NVIDIA の別の条件の部品（Omniverse Kit SDK・3D モデルなど）が要る。Isaac Lab は BSD-3-Clause（一部の拡張は Apache-2.0）で、Isaac Sim と組み合わせて使う場合は、Isaac Sim 側の条件もかかわる
- **状態**: 実用（Isaac Sim は正式なリリースが続いており、確認日の時点の最新は 6.2.0〈2026-10-14〉。Isaac Lab の正式な版の最新は 2.3.2〈2026-02-02〉で、3.0 は先行の版〈3.0.0-EA、2026-09-16〉の段階）。Isaac Sim の README が示す GPU の要件は、NVIDIA の GPU（ワークステーションでは RTX 4080 以上）
- **確認日**: 2026-10-17
- **情報源**: 一次

### ManiSkill

- **概要**: 物を扱う作業（マニピュレーション）に重点を置いた、ロボットのシミュレーションと学習の枠組み。物理と描画には SAPIEN を使う。GPU で多数の環境を並列に動かせ、並列の環境ごとに別の物体・場面を置くこともできる。強化学習・模倣学習・VLA の比較用の手法（ベースライン）や、実機で学んだ方策をシミュレータの中で評価する環境（real2sim）、シミュレータで学んだ方策を実機に移す例も用意している。現在の版 ManiSkill3 の論文は、国際会議 RSS 2025 で発表された。
- **一次情報**: [公式リポジトリ](https://github.com/mani-skill/ManiSkill)・[論文 arXiv:2410.00425](https://arxiv.org/abs/2410.00425)
- **種類**: OSS
- **ライセンス**: リポジトリは Apache-2.0。開発元によれば、剛体の環境はすべて Apache-2.0 などの制限の少ないライセンス。付属のアセット（3D のデータ等）は CC BY-NC 4.0（非営利に限る）
- **状態**: 実用（正式な版 3.0 が出ており、確認日の時点の最新は 3.0.1〈2026-04-21〉。README に研究用・試験的といった注意書きはない）。GPU での並列の計算は、開発元によれば Linux と NVIDIA の GPU の組み合わせでだけ使える
- **確認日**: 2026-10-17
- **情報源**: 一次

### Genesis World

- **概要**: フィジカルAIの開発のためのシミュレーションの基盤（旧名 Genesis）。開発元によれば、2024-12 に研究のプロジェクトとして始まり、現在は Genesis AI という企業が開発を支えている。剛体だけでなく、柔らかい物体・砂・液体・布などを1つの場面で一緒に計算する物理エンジン、自前の描画の仕組み、Python で書いた計算を各種の計算機向けに変換する仕組み（Quadrants）を、Python の使いやすい窓口でまとめている。開発元によれば、変換の先は NVIDIA の GPU（CUDA）に限らず、AMD の GPU（ROCm）・Apple の GPU（Metal）・Vulkan・一般の CPU にも対応する。
- **一次情報**: [公式リポジトリ](https://github.com/Genesis-Embodied-AI/genesis-world)
- **種類**: OSS
- **ライセンス**: Apache-2.0（ソースコード）
- **状態**: 実用（正式な版 1.x が出ており、確認日の時点の最新は 1.4.4〈2026-10-11〉。README に研究用・試験的といった注意書きはない）
- **確認日**: 2026-10-17
- **情報源**: 一次

### Gazebo

- **概要**: オープンソースのロボットのシミュレータ。現在の Gazebo は、旧来の Gazebo Classic を引き継いだもので、開発元によれば16年以上の開発の蓄積がある。複数の物理エンジンを使い分けられ、レーザー距離計・カメラ・IMU・GPS などのセンサーを、雑音のモデルつきで模擬できる。ROS（ROS 2 を含む）とつなぐためのパッケージ（ros_gz）を同じ開発元が公開しており、ROS 2 で作ったロボットのソフトウェアを、仮想の空間で動かして確かめる用途に向く。版には名前がつき、確認日の時点の最新の Jetty（2025-09）は長期の保守の対象（2031-05 まで）。
- **一次情報**: [公式リポジトリ（Gazebo Sim）](https://github.com/gazebosim/gz-sim)・[ROS とつなぐパッケージ ros_gz](https://github.com/gazebosim/ros_gz)・[公式の版の一覧](https://gazebosim.org/docs/latest/releases/)
- **種類**: OSS
- **ライセンス**: Apache-2.0
- **状態**: 実用（正式な版が続いており、確認日の時点の最新は Jetty〈2025-09〉で、2031-05 までの長期の保守の対象）
- **確認日**: 2026-10-17
- **情報源**: 一次

### O3DE

- **概要**: Open 3D Engine。ゲーム・映像・シミュレーションを作るための、オープンソースの 3D エンジン。企業が Open 3D Foundation の会員として開発を支えている。ロボットの用途では、ROS 2 とつなぐ部品（ROS2 の Gem。センサー・制御・ロボットのモデルの読み込みなど）が追加の部品集 o3de-extras で提供されている。このリポジトリの RAI とのつながりがあり、RAI の開発元のデモ（[agentic-mobile-manipulator](rai.md#agentic-mobile-manipulator)）は ROS 2・O3DE・RAI の組み合わせで作られている。また RAI のベンチマークにも O3DE を使うものがあり、外部の論文の評価に使われた例がある（[RHO](rai.md#rho-your-coding-agent-is-secretly-a-roboticist)）。
- **一次情報**: [公式リポジトリ](https://github.com/o3de/o3de)・[ROS 2 とつなぐ部品を含む o3de-extras](https://github.com/o3de/o3de-extras)・[公式サイト](https://o3de.org/)
- **種類**: OSS
- **ライセンス**: Apache-2.0 または MIT（利用者が選べる）。第三者の部品はそれぞれの条件に従う
- **状態**: 実用（正式なリリースが続いており、確認日の時点の最新は 2605.0〈2026-05-27〉）
- **確認日**: 2026-10-17

- **一次情報**: [arXiv:2507.00917](https://arxiv.org/abs/2507.00917)
- **種類**: 論文
- **ライセンス**: CC BY 4.0（arXiv の掲載ページの表示）
- **状態**: 研究段階（論文）
